# Rituraj Gupta — Vastu, Astro Vastu & Numerology Website

Official landing page and coming soon portal for **Rituraj Gupta** — Vastu, Astro Vastu & Numerology Consultant.

## Project Structure

- `rituraj-gupta-website.html` — Main website featuring consultant profile, three ancient sciences overview, guidance domains, interactive Pythagorean numerology calculator, testimonials, contact details, and booking links.
- `coming-soon.html` — Context-aware coming soon page for upcoming remedies catalog and blogs, with bi-directional navigation back to the main website.
- `index.html` — Root redirect to `rituraj-gupta-website.html` for GitHub Pages and web hosting platforms.

## Technologies Used

- Vanilla HTML5 & CSS3
- Embedded SVG/WebP assets for zero-latency loading
- Vanilla JavaScript (Pythagorean numerology engine, smooth spotlight interactions, responsive mobile drawer navigation, dynamic query parameter parsing)
- Google Fonts: *Libre Baskerville* & *ABeeZee*
